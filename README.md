# Look for unfamiliar words

学生课堂查词 / 标记生词网页。

**网站地址：<https://baiiugun.github.io/look-for-unfamiliar-words/>**

打开首页后选择“考试 / 文本”，再点开对应试卷直接进入，试卷页面会在“开始标记”弹窗里让学生填一次姓名拼音首字母（不留空格，例如 `LXM`；不用填生日，系统自动加上当天日期）。同一台设备上再打开其他试卷会自动记住，不用重复填写。试卷目录正在逐步添加，未配置的类别会提示“该类别的试卷目录尚未添加”。

**教师登录（查看标记结果）：<https://baiiugun.github.io/look-for-unfamiliar-words/标记单词结果-老师登录版本.html>**。页面公开可打开，但必须使用正确的 Supabase 教师账号登录才能读取学生数据。

此仓库由本地发布脚本同步生成；试卷目录配置和页面规范见本地“云同步信息”资料。
